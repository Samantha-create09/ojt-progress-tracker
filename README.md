# Task and Productivity Tracker

A responsive web application developed to organize internship tasks, schedules, learning notes, and mentor feedback in a structured and efficient manner.

## Features

* Task Creation and Management
* Internship Schedule Planning
* Calendar-Based Task Tracking
* Learning Notes Management
* Mentor Feedback Tracking
* Productivity Monitoring Dashboard
* Progress Analytics and Insights
* Responsive User Interface

## Technology Stack

### Frontend

* HTML
* CSS
* JavaScript
* Tailwind CSS

### Database

* MySQL

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Open the project folder and configure the database connection.

Run the application on a local server.

## Project Objective

The Task and Productivity Tracker helps interns manage daily tasks, monitor work progress, organize schedules, maintain learning records, and improve productivity through structured tracking and analytics.

Developed for improving internship workflow management and productivity tracking.
